# goit-markup-hw-06
# WebStudio – HTML & CSS (Part 6)

This project is the sixth homework from the GoIT HTML/CSS course.  
It contains the full layout for the WebStudio landing page with responsive design, navigation menu, modal window, and enhanced styling.

## 🧰 Technologies

- HTML5
- CSS3
- Git
- GitHub

## 🚀 Features

- Semantic HTML structure
- Advanced CSS layout
- Responsive design for different screens
- Navigation menu with mobile toggle
- Modal window
- Sections: Hero, Features, Team, Portfolio, Footer

## 📦 How to use

Open the `index.html` file in your browser to view the project.
